# 💣 지뢰찾기 (Minesweeper)

> 이 README는 게임을 완성한 뒤, 배포 직전 단계에서 작성합니다. 자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.

## 게임 소개
윈도우의 영원한 클래식, **지뢰찾기** 게임을 웹 환경에서 플레이할 수 있도록 구현한 토이 프로젝트입니다. 

* **기본 규칙**: 보드 위의 모든 지뢰를 피해 지뢰가 없는 모든 셀을 안전하게 열면 승리합니다.
* **숫자의 의미**: 셀을 열었을 때 나타나는 숫자는 해당 셀을 둘러싼 주변 8개 칸에 숨겨진 지뢰의 총 개수를 뜻합니다.
* **조작 방법**: 
  * **마우스 좌클릭**: 셀 열기 (지뢰를 밟으면 즉시 게임 오버)
  * **마우스 우클릭 / 롱터치**: 지뢰가 의심되는 곳에 깃발(Flag) 꽂기 또는 해제

## 어떻게 만들었나요
체계적인 개발 프로세스를 경험하기 위해 다음과 같은 흐름을 거쳐 단계별로 구현했습니다.

1. **PRD(제품 요구사항 정의서) 작성**: 게임의 필수 기능(지뢰 배치, 셀 오픈 logic, 타이머, 난이도 조절 등)과 예외 상황을 명확히 정의했습니다.
2. **Plan 확인 및 보완**: 구현 전 단계에서 에이전트와 함께 에러 가능성을 검토하고, 첫 클릭 시 지뢰가 터지지 않도록 보장하는 예외 처리 등의 설계를 보완했습니다.
3. **Agent 구현 및 디버깅**: 코드 작성 에이전트를 활용하여 코어를 빠르게 빌드한 뒤, 상태 관리 및 우클릭 이벤트(컨텍스트 메뉴 차단) 관련 사소한 버그들을 반복 피드백을 통해 완벽히 해결했습니다.

## freeform 버전과 비교했을 때
* **freeform 브랜치**: 초기 기획 구상 단계로, 규격화된 제한 없이 핵심 기능 위주로 빠르게 프로토타이핑을 진행한 버전입니다.
* **prd 브랜치 (최종 선택)**: 요구사항 정의서(PRD)를 철저히 준수하여 안정성을 높인 버전입니다. 난이도 전환에 따른 보드 리사이징이 유연하며, 타일 오픈 및 승리/패배 판정 조건이 엄격하게 검증되어 사용자에게 훨씬 완성도 높은 플레이 경험을 제공하므로 이 버전을 최종 선택했습니다.

## 커스터마이징한 부분
기본적인 모던 스타일 플랫 디자인 예시에서 탈피하여, 사용자의 감성을 자극할 수 있는 요소를 더했습니다.

* **Retro Windows UI**: 둥근 모서리와 부드러운 그림자를 걷어내고, 90년대 윈도우 특유의 **입체적인 회색 베벨(Bevel) 보더 테두리**를 적용했습니다.
* **클래식 배경화면**: 윈도우 95/98의 상징과도 같은 **레트로 청록색(`#008080`) 배경**을 깔아 오리지널 분위기를 연출했습니다.
* **7세그먼트 스타일 전광판**: 타이머와 남은 지뢰 수 표시 창을 **검은 바탕에 붉은색 디지털 전광판 폰트** 스타일로 디자인하여 시인성을 높였습니다.
* **원작 매칭 컬러 코드**: 1부터 8까지의 숫자 색상을 오리지널 지뢰찾기 시스템 컬러(1: 파랑, 2: 초록, 3: 빨강 등)와 100% 동일하게 매칭했습니다.
