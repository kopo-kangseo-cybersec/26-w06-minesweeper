# 💣 지뢰찾기

> 이 README는 게임을 완성한 뒤, 배포 직전 단계에서 작성합니다. 자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.

## 게임 소개

9×9, 16×16, 30×16 보드에서 지뢰를 피해 안전한 칸을 모두 여는 게임입니다. 좌클릭으로 칸을 열고, 우클릭으로 깃발을 표시할 수 있습니다.

## 어떻게 만들었나요

PRD를 작성해 필요한 기능을 정리하고, 구현 계획을 확인·보완한 뒤 Agent를 통해 HTML, CSS, JavaScript로 구현했습니다.

## freeform 버전과 비교했을 때

freeform 버전은 자유롭게 구현하고, PRD 버전은 요구사항과 구현 계획을 먼저 정리했습니다. 기능을 체계적으로 관리하고 요구사항을 빠짐없이 반영하기 위해 PRD 버전을 최종으로 선택했습니다.

## 실행 방법

index.html 파일을 브라우저에서 열어 실행합니다. style.css, script.js 파일은 같은 폴더에 있어야 합니다.
https://github.com/parksj7777/26-w06-minesweeper.git

## 커스터마이징한 부분

초급·중급·상급 난이도, 타이머, 남은 지뢰 수, 빈 영역 자동 공개, 숫자 칸 빠른 열기 기능을 추가했습니다. 첫 클릭 안전 기능과 반응형 화면도 적용했습니다.
